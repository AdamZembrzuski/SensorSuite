# Competitions

This folder is for storing AZSensorSuite competition entries and their supporting documentation.

Each competition should have its own subfolder containing the submitted entry (write-ups, photos, videos, presentation files, etc.) along with any notes on the results or feedback received.

> [!NOTE]
> This folder does not affect the build of the hardware, firmware, or software in this repository. It exists purely as an archive/record of where AZSensorSuite has been entered or showcased.

## Structure

Layout for each entry:

```
.competitions/
└── <competition-name>/
    ├── README.md        # Summary of the entry, category, and outcome
    ├── entry/           # Submitted materials (docs, slides, media, etc.)
    └── media/           # Supporting photos/videos, if not included above
```
